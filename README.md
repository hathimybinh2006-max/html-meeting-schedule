# Thực hành Bảng Lịch Họp Công Ty (rowspan & colspan)

Bài thực hành luyện tập sử dụng các thuộc tính gộp ô `rowspan` và `colspan` trong bảng HTML.

## Nội dung bài tập
- File chính: `index.html`
- Tiêu đề `<h1>`: "Lịch họp công ty"
- Các cột: Ngày, Giờ, Nội dung cuộc họp
- Kỹ thuật sử dụng:
  - `rowspan="2"`: Gộp ô cột "Ngày" khi có nhiều cuộc họp trong cùng một ngày.
  - `colspan="2"`: Gộp ô khi cuộc họp kéo dài cả buổi hoặc nhiều giờ liên tục.
